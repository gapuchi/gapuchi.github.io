# Machine learning

**Big picture:** a model, a cost, and a way to pick parameters that make the cost small. Classification is the same loop with a different model. Neural networks are that loop with more layers.

## Reading order

1. [Introduction](01-introduction.md): supervised learning, and what it means for a program to learn.
2. [Model and cost function](02-model-and-cost-function.md): linear regression, and the cost of a bad fit.
3. [Parameter learning](03-parameter-learning.md): gradient descent.
4. [Multivariate linear regression](04-multivariate-linear-regression.md): more than one input.
5. [Computing parameters analytically](05-computing-parameters-analytically.md): the normal equation, when you can skip the iteration.
6. [Classification](06-classification-and-representation.md): predicting a category instead of a number.
7. [Logistic regression](07-logistic-regression-model.md): the model and the cost for that prediction.
8. [Multiclass classification](08-multiclass-classification.md): more than two categories.
9. [Overfitting](09-solving-overfitting.md): a model that memorized the training set, and how to hold it back.
10. [Neural networks](10-neural-networks.md): layers of those models.
